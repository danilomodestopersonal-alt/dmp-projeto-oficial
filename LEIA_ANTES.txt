DMP — PACOTE DE ATUALIZAÇÃO 2026

1. Feche o VS Code antes de trocar pastas.
2. Guarde a pasta atual como backup.
3. Extraia este ZIP na Área de Trabalho.
4. Abra a nova pasta DMP_Projeto_Oficial no VS Code.
5. Execute npm install e npm run dev.
6. Faça login e teste antes de apagar qualquer backup.

Esta versão usa armazenamento local. A sincronização real entre computador e celular depende da conexão com o Supabase e será a próxima etapa.
